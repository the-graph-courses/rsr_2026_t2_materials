Question 01 / 10 Confounding

A third variable influences both the predictor of interest and the outcome. In regression language, that third variable is called a:

DAG clue
AA mediator (it sits on the causal path from X to Y)
BA confounder (it creates a non-causal association between X and Y)
CA residual (the leftover error after fitting the model)
Correct answer
B · Confounder

When Z causes both X and Y, the crude X→Y association mixes the true effect with a backdoor path through Z. Adjusting for Z in a multiple regression closes that path (for measured confounders).

Question 02 / 10 Adjusted slopes

In a multiple linear regression, each slope is interpreted as the change in the outcome associated with a one-unit increase in that predictor while:

R output clue
# two predictors in one model
lm(Y ~ X1 + X2, data = dat)
              Estimate
(Intercept)     10.2
X1              -0.8
X2               3.1
AHolding the other predictors in the model constant (adjusting / controlling for them)
BSetting every other predictor to its sample maximum
CAveraging the slope across all possible interaction terms
Correct answer
A · Holding other predictors constant

That is the meaning of an adjusted (partial) slope. Phrases like “controlling for” or “adjusting for” X2 mean: compare units that share the same X2 value.

Question 03 / 10 Why add predictors

A simple regression of Y on X shows a positive slope. After adding a confounder Z to the model, the slope on X flips sign. What does this pattern most clearly illustrate?

Scatter clue · dashed = crude fit; solid = within-Z fits
AThe outcome must be binary, so linear regression is invalid
BInteraction terms are required whenever a slope changes after adjustment
CConfounding can reverse (or hide) the apparent association; adjustment recovers the within-Z relationship
Correct answer
C · Confounding can reverse the crude association

Pooling groups that differ in Z can produce a misleading overall slope. Multiple regression fits the X→Y relationship while holding Z fixed, which can flip the sign relative to the crude model.

Question 04 / 10 Comparing coefficients

Two predictors enter the same model. One has Estimate = 0.05; the other has Estimate = 4.2. Why can you not conclude that the second predictor “matters more”?

R output clue
lm(Y ~ minutes + count, data = dat)
              Estimate
(Intercept)     8.00
minutes         0.05   # per minute
count           4.20   # per item
ABecause only standardized coefficients are ever interpretable
BBecause the predictors are on different units / scales, so raw slopes are not comparable head-to-head
CBecause the larger estimate always has the larger p-value
Correct answer
B · Different units / scales

A tiny per-minute slope can still imply a large change over an hour. A large per-item slope may describe a change that rarely occurs. Compare effects only after thinking about realistic contrasts on each predictor’s scale.

Question 05 / 10 Causal language

You adjust for measured confounders in an observational multiple regression and get a significant slope. The safest reporting phrase is:

Reminder
Adjusting closes backdoor paths only through confounders you measured. Unmeasured confounding and reverse causation can remain.
A“X is significantly associated with Y, controlling for [covariates]”
B“X causes Y; the regression proves the causal effect”
C“X has no relationship with Y once p < 0.05”
Correct answer
A · Association, controlling for covariates

Causal claims need a stronger design (e.g. randomization) or a carefully justified causal framework. Adjusted observational slopes support careful association language, not automatic “causes” wording.

Question 06 / 10 What is an interaction?

An interaction between predictors X and G means:

Visual clue
AX and G are perfectly correlated, so one must be dropped
BThe intercept is forced to equal zero for every group
CThe effect of X on Y depends on the level of G (group slopes need not be parallel)
Correct answer
C · Effect of X depends on G

An additive model assumes one shared slope (parallel lines). An interaction lets each level of G have its own slope for X. That is also called effect modification.

Question 07 / 10 R formula syntax

In an R formula, which expression expands to the two main effects plus their interaction?

Formula table
Write thisWhat R fits
Y ~ X + Gmain effects only (additive)
Y ~ X + G + X:Gmains + interaction
Y ~ X * G??? (this question)
AY ~ X:G alone (interaction without main effects)
BY ~ X * G (shorthand for X + G + X:G)
CY ~ X / G (nested slopes without an intercept)
Correct answer
B · Y ~ X * G

The colon : is the interaction term itself. The star * is the convenient expansion to both main effects and the interaction. Prefer including main effects when you fit an interaction.

Question 08 / 10 Reading interaction output

Reference group is G = 0. What is the slope of X when G = 1?

R output
lm(Y ~ X + G + X:G, data = dat)
              Estimate
(Intercept)      5.0
X                2.0    # slope when G = 0
G                4.0
X:G              1.5    # slope difference
A2.0 + 1.5 = 3.5
B2.0 only (the interaction is ignored for slopes)
C4.0 + 1.5 = 5.5
Correct answer
A · 3.5

The plain X coefficient is the slope in the reference group. Add the interaction coefficient to get the non-reference group’s slope: reference slope + X:G.

Question 09 / 10 Additive model

You fit lm(Y ~ X + G) with no interaction. Which statement is true?

Fitted lines (additive)
AEach group is allowed its own slope for X
BThe gap between groups must shrink as X increases
CGroups share one X slope; they may differ only by a constant intercept shift
Correct answer
C · Shared slope, intercept shift only

That is the additive (no-interaction) assumption: parallel fitted lines. To let slopes differ by group, add an X:G term.

Question 10 / 10 When to interact

Which practice is a good reason to include an interaction, rather than a bad one?

Decision checklist
  • Well established in the literature
  • It is the research question (does X’s effect depend on G?)
  • Strong design / biology suggests effect modification
  • Otherwise default to an additive model
AFit every pairwise interaction, keep only those with p < 0.05, and treat those p-values as confirmatory
BInclude the interaction because testing whether X’s effect depends on G is your pre-specified research question
CAlways include all interactions so the additive model is never used
Correct answer
B · Pre-specified research question

Fishing for significant interactions (option A) is p-hacking and invalidates those p-values. Default to additive models unless theory, design, or a planned question calls for an interaction.
