Intro to Statistical Tests: The t-test Family
Choosing and reading one-sample, two-sample independent, and paired t-tests
What every t-test does
The shared logic
A t-test is a tool for comparing 
categories / colors / means
. It asks whether an observed difference between means is larger than what random 
data entry / population census / sampling variation
 alone would produce, or whether that difference is real and 
descriptive / significant / categorical
.

The data are reduced to a single 
mode / median / t-statistic
, which is then converted to a 
box plot / sample size / p-value
.

If the p-value is below the chosen cutoff, called 
alpha / beta / sigma
 (commonly 0.05), we 
accept / prove / reject
 the null hypothesis. If it is above alpha, we 
confirm / disprove / fail to reject
 the null.

All three t-tests follow this same logic. They differ only in 
the p-value cutoff / the alpha level / which two means
 are being compared.
Signal over noise: the t-statistic
t =
estimate − null value
standard error
The top is the signal: how far the observed mean sits from the 
mean / median / null
 value.
The bottom is the standard error, the 
signal / bias / noise
 we expect from sampling.
A larger t means the signal stands out more, which gives a 
negative / smaller / larger
 p-value.
How large a t must be to count depends on the 
null mean / margin of error / degrees of freedom
, which grow with the sample size.
The three types of t-test
1 · One-sample
Compares one group's mean to a fixed 
target / before value / second group
, a known or claimed value.

Example: pills labeled 500 mg. Is the batch's mean dose really 500?

H₀: μ = 500
The target value goes in the 
paired / mu / data
 argument.

# one mean vs a target
t.test(pill, mu = 500)
2 · Two-sample independent
Compares the means of two separate groups made of 
repeated / the same / different
 individuals.

Example: pain relief in people given drug A vs people given drug B.

H₀: μA = μB
The null says the two means are 
zero / equal / paired
, so there is no difference.

# two separate groups
t.test(B, A)
3 · Paired (dependent)
Compares two measurements on the same individuals (or matched pairs).

Example: blood pressure before and after a drug, for each patient.

We run the test on each person's 
maximum / difference / total
; the null is that the mean difference is 
one / 500 / zero
.

H₀: μD = 0
# same units, measured twice
t.test(after, before,
       paired = TRUE)
We set 
FALSE / TRUE / 0
 for paired data. It equals a 
matched / one-sample / two-sample
 t-test on the differences.

Two-sided vs one-sided alternatives
Picking the alternative hypothesis
The null hypothesis is always an 
inequality / equality / range
 (for example μ = 500). The alternative sets which direction you test for.

Two-sided (H₁: μ ≠ target) detects a difference in 
either / only one / no
 direction, and it is the 
default / forbidden / rarest
 in R when you leave the argument out.

One-sided (H₁: μ > target, or μ < target) tests only 
one / both / zero
 direction.

Clinical work usually 
forbids / prefers / ignores
 two-sided tests: they catch both improvement and 
underperformance / sample size / rounding
, and they reduce 
random noise / directional bias / measurement error
 because the direction must be fixed in advance.

t.test(x, mu = 500, alternative = "two.sided")
# or "greater" / "less" for one-sided
Choose the alternative 
after / while / before
 you look at the data, never to chase a smaller p-value.
Where the p-value comes from
Two-sided: both tails count
One-sided: just one tail
For the same data, a one-sided test puts all of its rejection region in 
both / no / one
 tail. That is why a one-sided test is 
impossible / harder / easier
 to pass in its chosen direction, and why two-sided tests are the more 
stringent / lenient / random
 default.

Reading the t.test() output
Where the answer lives in R's output (two-sample)

  is not equal to 0

  1.12  8.44

mean in group online  mean in group inperson

Here p = 0.021 is below α = 0.05, so we 
reject / fail to reject / prove
 H0: the two group means are not equal.
The null for a two-sample test is that the true difference in means is 
4.8 / 0 / 74.2
.
The sample estimate gap is 74.2 − 69.4 = 
38.2 / 4.8 / 0.021
 points.
The 95% 
row name / confidence interval / null mean
 (1.12 to 8.44) excludes 0, which agrees with rejecting H0.
Practice
Identify the test
1. A water utility claims the average lead level at household taps is 5 ppb. Inspectors sample taps across the city to see whether the true mean differs from 5 ppb. This is a 
independent / paired / one-sample
 t-test.

2. Mean final-exam scores are compared for students in an online section and students in an in-person section. This is a two-sample 
dependent / independent / paired
 t-test.

3. The same warehouse pickers are timed on a packing task before and after ergonomics coaching. This is a 
one-sample / paired / independent
 t-test.

4. Mean monthly electricity use is compared between households with solar panels and households without. This is a two-sample 
paired / one-sample / independent
 t-test.

Intro to Statistical Tests: One-Way ANOVA
Comparing three or more group means with a single F-test instead of many t-tests
Why ANOVA? From two means to many
The idea
A t-test compares 
three / two / many
 means. ANOVA stands for 
a normal variable / analysis of variance / average of values
, and it extends that logic to compare three or more means, usually written as k group means.

It answers the question with one single 
z-test / F-test / t-test
 instead of many pairwise tests. Because it tests all groups at once, it is called an 
one-sided / omnibus / paired
 test.

Study (PREVEND): 500 Dutch adults take the RFFT cognition test. We ask whether mean RFFT score differs across the four 
age / education / blood-pressure
 groups (primary, lower & higher secondary, university).
The multiple-comparison trap
Why not just run a t-test on every pair? With 4 groups there are 
4 / 12 / 6
 possible pairs, so 6 separate t-tests.

Each test carries its own chance of a 
false positive / rounding error / true negative
 (about 0.05).

So with many groups you are likely to find a "significant" difference purely by 
proof / chance / design
, even when none exists. ANOVA controls this by testing everything 
one at a time / at once / never
.

P(≥1 false positive) = 1 − (0.95)6 ≈ 
5% / 50% / 26%
Hypotheses and the F-statistic
What we are testing
H₀: μ₁ = μ₂ = μ₃ = μ₄
The null says all k group means are 
zero / equal / different
, so there is no difference anywhere.

H₁: at least one μ differs
The alternative says at least one mean differs from the rest. Note it does not say which one. A significant result only tells us that 
at least one / no / every
 true mean is different.

We decide using the 
F-statistic / t-score / median
: a large F is evidence of a real difference; an F near 
100 / 20 / 1
 is not.
The F-ratio: between over within
F =
MS between
MS within
=
variance between groups
variance within groups
MS between is the variance between the group means, the 
noise / signal / cutoff
. MS is short for 
margin of safety / most significant / mean square
, another name for a variance.
MS within is the variance within each group, the 
signal / mean / noise
 in the data.
Each MS = its sum of squares divided by its 
degrees of freedom / p-value / sample mean
. Big between and small within → 
small / large / negative
 F.
The two variances behind F
Numerator · MS between
grand mean
prim
low sec
hi sec

SSbetw

We square each group-mean-to-grand-mean gap, weight it by the group's 
sample size / median / variance
, add them up, and divide by df. The further apart the group means, the 
larger / flatter / smaller
 this numerator, and the bigger the F.

Denominator · MS within
prim
low sec

Purple lines = distance from each person to their own group mean.
MSwith =

 ,   SSwith = ΣΣ (xij − xj)2
This measures the 
noise / signal / mean
 inside groups. More within-group scatter raises MS within, and since it sits in the 
numerator / exponent / denominator
, that lowers F and gives 
more / certain / less
 evidence of a difference.

What makes F large or small
Three pictures: same four groups, very different F
Low F: small between, large within → F = 
high / low / medium
High F: large between, small within → F = 
medium / low / high
Medium F: large between and large within → F = 
medium
Tightly clustered points that still sit far apart (middle panel) are the strongest evidence: the small within-group spread makes it unlikely the gaps are just 
random variation / measurement units / true signal
. Wide scatter (right panel) means the same group gaps could plausibly come from 
no / four / one
 shared distribution.

Which pairs differ? Tukey's HSD follow-up
Tukey HSD follow-up
A significant ANOVA only says at least one mean differs, not 
whether / which / how many

False Positives, False Negatives & Power
The two ways a test can mislead you, and the power to catch a real effect
Two errors, two truths
Type I error → FALSE POSITIVE
crying wolf
A Type I error happens when we 
accept / reject / ignore

false / random / true

repeat / exist / vanish

positive / neutral / negative

Three examples of a false positive
Courtroom: an 
innocent / guilty / repeat

Medical test: a 
healthy / elderly / sick
 patient is told they have the disease.

Height study: an unlucky sample makes two groups look

Power: catching a real effect
Power = the chance you catch a real effect
Power is the probability that we 
correctly reject / re-run / quietly accept

Sample size for a two-sample t test in R
Before you collect data, you decide how many subjects to recruit. In this practical, you will use the R function power.t.test() to calculate the sample size for a given power.

Overview 
Deciding how many subjects to recruit is one of the more important decisions you make when planning a study.

If you recruit too few subjects, your study may be underpowered and you may miss a real effect.

It’s also possible to recruit too many subjects, more than the study needs to demonstrate a convincing effect, and thus waste time and money.

A power analysis is usually done before the study is conducted, to determine the sample size needed to achieve a desired level of power.

There are many kinds of power analysis for different study designs and tests. This practical introduces the idea through one common case: finding sample size for a two-sample t test using the R function power.t.test().
