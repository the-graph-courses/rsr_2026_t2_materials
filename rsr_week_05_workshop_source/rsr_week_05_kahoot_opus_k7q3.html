Week 5 Warm-up Quiz

t-tests, ANOVA, Type I/II errors, sample size and power. Prep for the K6 distress table exercise.

1.t-test vs ANOVA

What is the main difference between a t-test and a one-way ANOVA?
  1. AANOVA needs normal data, but a t-test does not
  2. BA t-test is for two groups, ANOVA is for more groups
  3. CA t-test is for paired data, ANOVA is for unpaired data
B. A t-test compares two means; ANOVA extends the same signal-over-noise idea to three or more. In the exercise you use a t-test for Gender, Marriage and Wuhan history, and an ANOVA for Age category (4 groups).

2.shared logic

Both tests reduce the data to one statistic, which is then turned into a...
  1. Astandard deviation
  2. Bbox plot
  3. Cp-value
C. A t-test gives a t-statistic and ANOVA gives an F-statistic, and both map to a p-value. If the p-value is below alpha (usually 0.05), we reject the null.

3.signal and noise

The t-statistic is signal divided by noise. What makes it larger (and the p-value smaller)?
  1. AA bigger gap between means, or less noise
  2. BA bigger standard error
  3. CA higher chosen alpha
A. A wider separation of the means (top) or a smaller standard error (bottom) moves t further from zero, which shrinks the p-value. Alpha is just the cutoff and does not change t.

4.choosing the test

We compare mean K6 distress for people who did vs did not visit Wuhan. These are two separate groups of different people. Which test fits?
  1. AOne-sample t-test
  2. BTwo-sample t-test
  3. CPaired t-test
B. Two separate groups of different people means a two-sample (independent) t-test. It is not paired (no before and after on the same person) and not one-sample (no fixed target value).

5.reading t output

From this gender t-test, what do we conclude at alpha = 0.05?
data:  total_scores_of_K6 by Gender
t = -2.86,  df = 1597,  p-value = 0.0043
95 percent confidence interval:  -1.41  -0.26
mean Female = 7.9     mean Male = 8.7
  1. AFail to reject the null; the means look equal
  2. BReject the null; the mean scores differ
  3. CThe result is invalid because t is negative
B. p = 0.0043 is below 0.05, and the confidence interval (-1.41, -0.26) excludes 0, so both agree. The negative sign only reflects the group order (Female minus Male); its size is what matters, not its sign.

6.reading ANOVA output

In this Age-category ANOVA, which value is the p-value?

Residuals15953321520.8
  1. APr(>F) = 2.1e-06
  2. BF value = 9.8

7.what ANOVA tells you

The age ANOVA is significant. What does that tell us?
  1. AEvery age group differs from every other group
  2. BThe oldest group has the highest distress
  3. CAt least one age group differs from the rest
C. ANOVA is an omnibus test: it flags that some difference exists but not which groups or in which direction. To find which pairs differ you run a follow-up such as TukeyHSD().

8.Type I error

What is a Type I error?
  1. AFailing to detect a real effect
  2. BClaiming an effect that is not really there
  3. CPicking the wrong test for your data
B. A Type I error rejects a true null: a false positive, like convicting an innocent person. Its probability is alpha. Missing a real effect (option A) is a Type II error.

9.which error is possible

The gender test was significant, so we rejected the null. Which error could we be making?
  1. AA Type II error, missing a real effect
  2. BNo error is possible once a result is significant
  3. CA Type I error, a false positive
C. When you reject the null, the risk is a false positive (Type I): maybe there is truly no difference and this sample was unlucky. You can only make a Type II error when you fail to reject.

10.multiple testing

With 4 age groups, how many separate pairwise t-tests would cover every pair?
  1. A4
  2. B6
  3. C12
B. Four groups give 6 pairs. That is why we prefer a single ANOVA over six separate t-tests, as the next question shows.

11.false positives pile up

Run those 6 t-tests at alpha = 0.05. Roughly what is the chance of at least one false positive?
  1. AStill 5%
  2. BAbout 1%
  3. CAbout 26%
C. 1 minus 0.95 to the 6th power is about 0.26. Running many tests inflates the false-positive rate, so you would likely find a "significant" pair by chance even if no groups truly differ. ANOVA tests all groups at once and keeps the rate near 5%.

12.why calculate sample size

You give R the four values below and leave out n. What does power.t.test() give back?
power.t.test(delta = 2, sd = 4.6, sig.level = 0.05, power = 0.80)
# delta = difference worth detecting, sd = spread
# sig.level = false-positive rate, power = chance to detect
  1. AProof that the intervention works
  2. BThe number of people needed per group
  3. CThe p-value your study will get
B. You supply delta, sd, sig.level and power, and R solves for n, the sample size per group. Too few people leaves you underpowered and you miss real effects; too many wastes time and money. You do this before collecting data.

13.power and effect size

Your study has 80% power to detect a 2-point drop. If the true effect is actually 4 points, your chance of detecting it is...
  1. AHigher than 80%
  2. BLower than 80%
  3. CStill exactly 80%
A. Power was set for the smallest difference worth detecting. A bigger true effect separates the groups more, so it is easier to detect and your real power is even higher.

14.sample size trade-off

You change the difference worth detecting from 2 points down to 1 point, keeping everything else the same. The required n per group...
  1. AGoes down
  2. BStays the same
  3. CGoes up
C. A smaller target difference is harder to detect, so you need more people (roughly four times as many when you halve the difference). Raising the target power from 0.80 to 0.90 also increases n.

15.building the table

In the exercise table, why are the t/F and p-value shown only on the first row of each characteristic?
  1. ABecause R can only print one number per block
  2. BBecause one test covers the whole characteristic, not each row
  3. CBecause the other rows had missing data
B. Each characteristic gets a single group-level test (one t-test or one ANOVA), so its statistic and p-value belong to the whole block. The code uses row_in_block == 1 to print them once instead of repeating them on every row.
