Q1 t-tests & ANOVA · shared logic
What do a two-sample t-test and one-way ANOVA have in common?
Both ask whether group-mean differences exceed what sampling variation alone would produce, then convert a test statistic to a p-value.
Larger statistic → smaller p-value (same idea for F in ANOVA).
ABoth require exactly two groups to run without error
BBoth compare group means and produce a p-value testing a no-difference null
CBoth report which specific pairs of groups differ from each other
Answer: B — Same core logic; t-tests handle two groups (or one vs a target), ANOVA handles three or more in one omnibus test. Neither names the pairs — follow-up tests like Tukey HSD do that.
Q2 Workshop exercise · choosing the test
In the K6 distress exercise, which characteristic gets a one-way ANOVA?
# Step 3 — two groups → t.test(); three+ → aov()
gender_t   <- t.test(total_scores_of_K6 ~ Gender,   data = survey, var.equal = TRUE)
age_aov    <- aov(total_scores_of_K6 ~ `Age category`, data = survey)
marriage_t <- t.test(total_scores_of_K6 ~ Marriage, data = survey, var.equal = TRUE)
AGender
BHistory of visiting Wuhan
CAge category
Answer: C — Age has four groups (18–30, 31–40, 41–50, >50). Gender, Marriage, and Wuhan history each have two levels and get t-tests.
Q3 Multiple comparisons
With 4 groups, how many separate pairwise t-tests cover every pair?
A4 pairs
B6 pairs
C8 pairs
Answer: B — Formula k(k−1)/2: with k = 4, that is 6. Each test carries its own false-positive risk.
Q4 Multiple testing · inflated Type I error
Six independent tests, each at α = 0.05. Roughly what is P(at least one false positive)?
1 - (0.95)^6   # ≈ 0.265
AAbout 5%
BAbout 26%
CAbout 50%
Answer: B — P(no false positive) = 0.95⁶ ≈ 0.74, so P(≥1) ≈ 26%. This is the multiple-comparison trap; ANOVA uses one omnibus F-test instead.
Q5 ANOVA · F-ratio
In one-way ANOVA, F equals which ratio?
AWithin-group variance divided by between-group variance
BTotal sample variance divided by number of groups
CBetween-group variance divided by within-group variance
Answer: C — F = MS_between / MS_within. Big between spread and small within scatter → large F → small p.
Q6 Reading ANOVA output
At α = 0.05, what do you conclude from this output?
fit <- aov(RFFT ~ education, data = prevend)
summary(fit)
             Df  Sum Sq  Mean Sq  F value  Pr(>F)
education     3  115000    38333    73.3   <2e-16 ***
Residuals   496  259000      522
AFail to reject the null; all education-group means appear equal
BReject the null; at least one education-group mean differs
CReject the null; every pair of education groups differs
Answer: B — p < 2e-16 is far below 0.05. Report F(3, 496) = 73.3, p < 0.001. ANOVA does not tell you which pairs — use Tukey HSD for that.
Q7 ANOVA · degrees of freedom
In F(3, 496) from the PREVEND education ANOVA (k = 4 groups, N = 500), what do 3 and 496 mean?
A3 = number of groups; 496 = total sample size
B3 = within-groups df; 496 = between-groups df
C3 = between-groups df (k−1); 496 = within-groups df (N−k)
Answer: C — First df is between (k−1 = 3), second is within/residual (N−k = 496). Mean Sq = Sum Sq ÷ Df; F ≈ 38,333 ÷ 522.
Q8 Type I error
When does a Type I error (false positive) occur?
AFail to reject H₀ when a real effect exists
BReject H₀ when H₀ is actually true (no real effect)
CReject H₀ when a real effect exists
Answer: B — Type I = false positive, probability α per test when H₀ is true. Example: reporting a significant gender difference in K6 when none exists in the population.
Q9 Type II error
A drug truly lowers K6 distress, but the study gives p = 0.34 and you fail to reject H₀. Which error?
AType I — false positive; an effect was claimed wrongly
BTrue positive — the effect was detected correctly
CType II — false negative; a real effect was missed
Answer: C — Type II = β. H₀ is false (drug works) but you fail to reject. Often caused by too-small sample size / low power.
Q10 α and false positives
Setting α = 0.05 means that if H₀ is true, each individual test has about a 5% chance of what?
AA false negative — missing a real effect by chance alone
BA true negative — correctly keeping H₀
CA false positive — rejecting H₀ by chance alone
Answer: C — α is the per-test false-positive rate. sig.level = 0.05 in power.t.test() is the same idea. Many tests inflate the chance of at least one false positive.

Q12 Table logic
Why does the gt table show t/F and p on only the first row of each characteristic block?
`t/F` = if_else(row_in_block == 1, stat_text, "")
p     = if_else(row_in_block == 1, p_text, "")
AThe gt package can only print one statistic per variable block
BEach characteristic has one test covering all its groups together
COnly the first group label in each block was included in the test
Answer: B — Gender: one t-test (Male vs Female). Age: one ANOVA (four groups). The stat and p describe the whole comparison, not each row separately.
Q13 Power analysis · purpose
What is the main point of a sample-size calculation before you collect data?
Part 2 of the exercise uses pilot K6 SD to plan a follow-up trial. Too few → underpowered (Type II risk). Too many → wasted resources.
AConfirm the intervention will produce p < 0.05 in the final analysis
BCalculate the exact p-value you will get after data collection
CEstimate how many participants per group you need for adequate power
Answer: C — Plan sample size from delta, sd, sig.level, and power. Run it before the study, not after.
Q14 power.t.test()
In this call, which value does R calculate for you?
power.t.test(
  delta     = 2,
  sd        = pilot_sd,
  sig.level = 0.05,
  power     = 0.80,
  type      = "two.sample"
)
# R returns n ≈ 44.7 → round up to 45 per group
Adelta — minimum effect worth detecting
Bn — sample size per group
Cpower — probability of detecting a real effect
Answer: B — Supply four inputs, omit n. R returns n; always round up to a whole number.
Q15 Power · changing delta
sd, sig.level, and power stay fixed. You change delta from 2 points to 1 point. What happens to required sample size?
# delta = 2 → n ≈ 45 per group
# delta = 1 → n ≈ 176 per group
AIt goes down — a smaller delta is easier to detect
BIt stays the same — delta does not enter the calculation
CIt goes up — a smaller target effect needs more participants
Answer: C — Smaller delta = harder to detect = larger n. Prework example: delta 5 → n ≈ 42; delta 8 → n ≈ 17. Bonus: if the true effect exceeds delta, actual power is higher than planned.
