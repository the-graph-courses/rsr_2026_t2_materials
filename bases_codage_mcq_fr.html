Question 1Commentaires

Vrai ou faux : les deux morceaux de code ci-dessous sont des façons valables de commenter du code ?

# Additionnez deux nombres 2 + 2
2 + 2 # Additionnez deux nombres
Tout ce qui suit # sur une ligne est ignoré par R.
  • A. Vrai
  • B. Faux
Réponse : A
Les commentaires peuvent être sur une ligne entière ou à la fin d'une commande, après le symbole #.
Question 2Calculatrice

Dans l'expression suivante, quel signe est évalué en premier par R ?

2 - 2 / 2
## [1] 1
R respecte l'ordre des opérations (division avant soustraction).
  • A. Le signe moins (−)
  • B. Le signe de division (/)
  • C. Les deux en même temps
Réponse : B
La division est évaluée en premier : 2 / 2 = 1, puis 2 − 1 = 1.

Question 5Erreurs

Le code ci-dessous renvoie une erreur. Pourquoi ?

mon_prenom <- "Kene" mon_nom <- "Nwosu" mon_prenom + mon_nom
Erreur : argument non numérique à l'opérateur binaire
  • A. On ne peut pas additionner deux chaînes de caractères avec +
  • B. Les objets mon_prenom et mon_nom n'existent pas
  • C. Il manque un point-virgule entre les lignes
Réponse : A
L'opérateur + ne fonctionne que pour les nombres. Pour assembler du texte, utilisez paste().
Question 6Noms d'objets

Nous essayons de prendre les 20 premières lignes de ebola_data. Quelle ligne fonctionnera correctement ?

20_premieres_lignes <- head(ebola_data, 20) vingt-premieres-lignes <- head(ebola_data, 20) premiere_20_lignes <- head(ebola_data, 20)
Les noms d'objets doivent commencer par une lettre et ne contenir que lettres, chiffres, points et traits de soulignement.
  • A. 20_premieres_lignes <- head(ebola_data, 20)
  • B. vingt-premieres-lignes <- head(ebola_data, 20)
  • C. premiere_20_lignes <- head(ebola_data, 20)
Réponse : C
A commence par un chiffre (invalide). B contient des tirets (invalide). C utilise la forme serpent recommandée.
Question 7Fonctions

Nous voulons les 6 premières lignes du jeu de données intégré women. Quelle ligne n'est pas valide ?

head(women) head(women, 6) head(x = women, 6) head(x = women, n = 6) head(6, women)
Sans noms d'arguments, l'ordre compte : d'abord l'objet (x), puis le nombre de lignes (n).
  • A. head(women)
  • B. head(x = women, n = 6)
  • C. head(6, women)
Réponse : C
head(6, women) inverse l'ordre des arguments sans les nommer, ce qui provoque une erreur.
Question 8Imbrication

Parmi ces exemples d'imbrication de fonctions, lequel contient une erreur ?

sqrt(head(women)) paste(sqrt(9), "plus 1 est", sqrt(16)) sqrt(tolower("LUIGI"))
La sortie d'une fonction peut être passée directement comme argument à une autre.
  • A. sqrt(head(women))
  • B. paste(sqrt(9), "plus 1 est", sqrt(16))
  • C. sqrt(tolower("LUIGI"))
Réponse : C
tolower() renvoie du texte ; sqrt() attend un nombre. On ne peut pas calculer la racine carrée d'une chaîne de caractères.

Question 10Packages

Au début d'un script R, nous voulons installer et charger le package {janitor}. Quelle approche est recommandée ?

# Option A if(!require(pacman)) install.packages("pacman") pacman::p_load(janitor) # Option B install.packages("janitor") library(janitor) # Option C install.packages("janitor") pacman::p_load(janitor)
  • A. Option A : pacman::p_load(janitor) après avoir installé {pacman} si nécessaire
  • B. Option B : install.packages() puis library() à chaque exécution
  • C. Option C : install.packages("janitor") à chaque exécution du script
Réponse : A
p_load() installe automatiquement les packages manquants et les charge. On n'installe {pacman} qu'une fois, avec la vérification if(!require(pacman)).
